# Dustin Brentz — Product Design Portfolio

Personal site for Dustin Brentz, Lead / Senior Product Designer.

Static pages for Home, Product Design, and Graphic Design, plus the resume PDF. Images open in a lightbox, and prototype clips play inline.

```bash
python3 -m http.server 8765
```

`scripts/build_site.py` rebuilds the pages from `data/product-galleries.json` and `data/graphic-galleries.json`.
